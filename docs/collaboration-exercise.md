# Collaboration conflict exercise

Use this small fixture only for `ms-git-collab`. The assignment intentionally asks two branches to edit the same line so the merge conflict is deterministic and safe to resolve.

Shared status: We prefer verifying the change with focused checks and the build, while the peer prefers running the full test suite.

## Team practice

To reduce similar conflicts on a real team, communicate before editing shared lines, keep changes focused, and avoid unnecessary edits to the same lines.
